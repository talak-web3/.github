# Talak-web

**Building better security tools for the modern web.**

Talak means **"better"** in Amharic. We build open-source, security-first tools that help developers create, secure, and investigate modern applications.

## Projects

| Project | Description |
|---------|-------------|
| **talak-web3** | Security-first Web3 backend and authentication toolkit. |
| **Talak-OSINT** | Open-source intelligence and investigation framework. |
| **Talak-auth** | Secure authentication framework. |
| **Talak-cli** | Official command-line interface. |
| **Talak-Scan** | Security scanning toolkit. |
| **Talak-audit** | Automated security auditing tools. |
| **Talak-monitor** | Security monitoring and observability platform. |
| **Talak-intel** | Threat intelligence utilities. |
| **Talak-graph** | Relationship and intelligence graph engine. |
| **Talak-Web-examples** | Examples, templates, and reference implementations. |
